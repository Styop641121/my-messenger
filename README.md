# Իմ մեսենջերը

Android հավելված՝ հաղորդագրություններով և ձայնային/տեսազանգով։ Տեղադրվում է APK ֆայլով, առանց Play Market-ի։

## Ինչպես ստանալ APK ֆայլը (մեկ անգամ, ~15 րոպե)

APK-ն կառուցում է GitHub-ը՝ անվճար։ Քեզ պետք է միայն անվճար GitHub հաշիվ (github.com)։

1. Մտիր github.com, ստեղծիր հաշիվ (եթե չունես)։
2. Վերևի աջ անկյունում սեղմիր **+** → **New repository**։ Անունը՝ `my-messenger`։ Ընտրիր **Public** (այդ դեպքում կառուցումն անվճար է և անսահմանափակ) և սեղմիր **Create repository**։
3. Բացված էջում սեղմիր **uploading an existing file**։
4. Բացիր այս zip-ը քո համակարգչում և **բոլոր ֆայլերն ու թղթապանակները** (`app`, `.github`, `build.gradle.kts`, `settings.gradle.kts`, `gradle.properties`, `.gitignore`) քաշիր GitHub-ի էջ։ Սպասիր, մինչև բեռնումն ավարտվի, հետո ներքևում սեղմիր **Commit changes**։
   - Եթե `.github` թղթապանակը չի երևում (թաքնված է), միացրու «թաքնված ֆայլերի ցուցադրումը» կամ տես ներքևի «Եթե .github-ը չբեռնվեց» բաժինը։
5. Բացիր **Actions** ներդիրը։ Եթե GitHub-ը թույլտվություն խնդրի, սեղմիր **I understand my workflows, go ahead and enable them**։
6. Ձախից ընտրիր **Build APK**, աջից սեղմիր **Run workflow** → **Run workflow**։ (Եթե արդեն ավտոմատ սկսել է, սա պետք չէ։)
7. Սպասիր 5–10 րոպե, մինչև կետը դառնա կանաչ ✓։
8. Սեղմիր այդ կանաչ կառուցման վրա։ Էջի ներքևում «Artifacts» բաժնում սեղմիր **my-messenger-apk**. կներբեռնվի zip։ Այն բացիր, ներսում կա **app-debug.apk**։ Սա է քո հավելվածը։

Եթե կետը կարմիր է, սեղմիր դրա վրա, պատճենիր սխալի տեքստը և ուղարկիր ինձ, կուղղեմ։

## Ինչպես տեղադրել հեռախոսում

1. Ուղարկիր `app-debug.apk` ֆայլը ընկերոջդ (Telegram, էլ. փոստ, USB, ցանկացած եղանակով) և ինքդ էլ տեղադրիր քո հեռախոսում։
2. Հեռախոսում բացիր ֆայլը։ Android-ը կասի, որ անհայտ աղբյուրից տեղադրումը արգելված է։ Սեղմիր **Settings** և թույլ տուր այդ հավելվածին (օրինակ՝ Telegram-ին կամ Files-ին) տեղադրել հավելվածներ։
3. Եթե Google Play Protect-ը զգուշացնի, սեղմիր **Install anyway** (Այնուամենայնիվ տեղադրել)։ Դա նորմալ է, քանի որ հավելվածը Play Market-ում չէ։
4. Բացիր «Իմ մեսենջերը»։

## Ինչպես օգտվել

1. Առաջին բացելիս գրիր քո անունը և ընտրիր ID (լատինատառ, օրինակ `aram77`)։ ID-ն քո հասցեն է. ընկերը քեզ գտնում է դրանով։
2. Վերևի աջ անկյունում «Իմ ID» կոճակից պատճենիր կամ կիսվիր քո ID-ով և ուղարկիր ընկերոջդ։ Նրանից էլ ստացիր իր ID-ն։
3. Սեղմիր **+**, մուտքագրիր ընկերոջ ID-ն և սկսիր զրույցը։
4. Վերևում հեռախոսի պատկերակը ձայնային զանգ է, տեսախցիկինը՝ տեսազանգ։

## Կարևոր սահմանափակումներ

- Հաղորդագրությունը հասնում է, երբ **երկու հեռախոսներում էլ հավելվածը բաց է** և կա ինտերնետ։ Եթե ընկերդ օֆլայն է, հաղորդագրությունը մնում է «ուղարկվում է…» վիճակում և ինքնաբերաբար կուղարկվի, երբ նա միանա (մինչ այդ քո հավելվածը պետք է բաց լինի)։
- Փակ կամ ֆոնային հավելվածը ծանուցումներ չի ցույց տալիս և զանգ չի ստանում։
- Կապը գնում է ուղիղ հեռախոսից հեռախոս և գաղտնագրված է։ Իրար գտնելու համար օգտագործվում է PeerJS-ի անվճար հանրային սերվերը։ Երբեմն (կախված օպերատորից) ուղիղ կապը չի հաջողվում, և զանգը չի միանում։
- Հաշիվ և գաղտնաբառ չկա. ID-ն գիտեցող ցանկացած մարդ կարող է քեզ գրել կամ զանգել, իսկ ID-ն քո տվյալները չի պաշտպանում։ ID-ն տուր միայն նրանց, ում վստահում ես։ Եթե երկար ժամանակ հավելվածը չօգտագործես, ուրիշը կարող է վերցնել քո ID-ն։
- Հաղորդագրությունները պահվում են միայն հեռախոսի հիշողության մեջ։ Հավելվածը հեռացնելիս դրանք կկորչեն։

## Եթե .github-ը չբեռնվեց

GitHub-ի էջում սեղմիր **Add file → Create new file**։ Անվան դաշտում գրիր `.github/workflows/build.yml` (թեք գծերը ինքնաբերաբար կստեղծեն թղթապանակներ), իսկ պարունակության մեջ տեղադրիր zip-ի արմատում գտնվող `build.yml` ֆայլի ամբողջ տեքստը և սեղմիր **Commit changes**։
